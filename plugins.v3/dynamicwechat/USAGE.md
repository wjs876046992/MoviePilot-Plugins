# 动态企微可信IP（DynamicWeChat · V3）

检测本机公网 IP 变化，自动登录企业微信管理后台并更新应用的「可信IP」白名单，
让 Server酱、企微应用消息等依赖固定出口 IP 的通知在动态公网 IP 下持续可用。

本版本是 V3 专用实现（需要 MoviePilot v3.0.0 及以上）。功能与原先放在 V2 目录的
3.0.2 一致，宿主访问已收敛到 `app.sdk` 稳定入口。V2 目录已回滚到上游 2.1.9，
仅供旧版宿主使用。

## 工作原理

1. 检测公网 IP，优先级：DDNS 域名解析 > 多 WAN 多出口 > 公网 IP 探测 URL。
2. 使用 Cookie（本地缓存或 CookieCloud）驱动无头浏览器（CloakBrowser）登录
   企业微信管理后台。
3. 逐应用打开「企业可信IP」配置，填入最新 IP（多 WAN 时全部出口 IP 合并填入，
   固定可信IP始终保留），确认提交。
4. 每 10 分钟独立保活循环校验 Cookie；失效时先尝试从 CookieCloud 恢复，
   仍失败则通知用户。

## 配置项

配置页为五张卡片分区：基础、扫码登录、IP 来源、通知、高级。每张卡顶部有标题和一句说明。

| 配置 | 必填 | 说明 |
|---|---|---|
| 启用插件 | - | 总开关 |
| 立即检测一次 | - | 保存后立即执行一轮检测 |
| 强制更新IP | - | 不等 IP 变化，直接用 Cookie 改一次可信IP |
| 检测周期 | ✅ | cron 表达式，如 `0 * * * *`（每小时）；留空或非法时详情页会红条提示且检测不运行 |
| 应用ID | ✅ | 企业微信应用页面 URL 末尾的 ID；多个用英文逗号分隔。**不要填 `100000x` 开头的自建应用**，插件只支持自建应用的通讯录同步应用 ID（详见作者主页说明） |
| 本地扫码修改IP | - | 首次使用勾选并保存，然后到详情页扫码 |
| DDNS域名 | - | 填写后优先解析该域名获取动态公网IP（frpc 等场景下容器拿到的是真实公网IP而非容器出口IP）；**支持多个域名**（英文逗号分隔），全部解析后合并去重一起填入可信IP，单个失败不影响其余；全部失败时不改动可信IP，详情页红条提示 |
| 多WAN多出口 | - | 开关；打开后从多个多出口检测站抓取中国大陆出口 IP 全部填入 |
| 最多保留出口IP数 | - | 仅多WAN模式，默认 3 |
| 自定义公网IP探测地址 | - | 仅单IP模式生效，逗号分隔；留空用内置探测站 |
| 固定可信IP | - | 始终保留在可信IP列表中的固定 IP，多个用英文逗号分隔；与所选检测来源合并后一起填入 |
| 使用CookieCloud | - | （高级区）Cookie 存取走 CookieCloud（本地内建或自定义服务器，取自 MoviePilot 设置） |
| MP内置通知 | - | Cookie 失效/IP 更新通知走 MoviePilot 配置的通知渠道；是否送达页面无法查询，可用通知区的「测试通知推送」按钮验证 |
| 第三方通知Token | - | Server酱（sct开头）/ IYUU / PushPlus，多个用 `||` 分隔；结尾加 `||Q` 表示改IP成功时不发送通知；「IP变动后通知」开关需要先填此项 |

## 首次使用

1. 填「检测周期」和「应用ID」，保存。
2. 勾选「本地扫码修改IP」再保存一次，进入插件详情页，在「扫码登录」卡查看二维码
   （页面是快照，生成后需刷新本页）。
3. 扫码后若触发短信验证码，把 6 位验证码以 `？` 结尾发到企业微信应用
   （如 `110301？`），或用 `/wxcode 110301` 命令提交。
4. 之后插件自动保活。Cookie 失效时按通知提醒重新扫码即可，无需重复配置。

## 远程命令

- `/push_qr`：立即向配置的通知渠道推送登录二维码。
- `/wxcode <6位验证码>`：提交短信验证码（与以 `？` 结尾直接回复等价）。

## 详情页

详情页为三张卡片分区，与配置页风格一致。打开即可回答「Cookie 活不活、
两个后台任务在不在跑、卡在哪一步」：

- 【运行状态】插件总开关（绑定实际校验结果）/ Cookie 登录态（尚未登录、
  有效并显示保活时长、已失效、连续多次无法确认）/ 保活校验（每 10 分钟一轮，
  显示上次结果与原因）/ IP 检测（检测周期、上次结论、当前可信IP）。
- 【IP 来源】DDNS 状态（正常显示解析到的 IP 列表 / 全部失败红条）、
  固定可信IP（个数或格式错误提醒）、当前模式与已填入的可信IP 汇总。
- 【扫码登录】二维码状态（没有任务灰 / 运行中黄，提示刷新本页 / 有效绿+图片）、
  验证码等待条（等待时显示，含两种提交方式）。

页面是进入时的快照，扫码等待期间需手动刷新；测试通知按钮在配置页的通知区。

## 常见问题

- **二维码一直不过期/看不到**：二维码约 110 秒过期，重新勾「本地扫码修改IP」保存即可刷新。
- **Cookie 失效通知发不出**：MP 内置通知和第三方通知都失败时会写入站内消息；
  如果两者都没配，详情页的红条会持续提示。
- **多 WAN**：配置页打开「多WAN多出口」开关，可选填「最多保留出口IP数」（默认 3）；
  旧版写在应用ID里的「||wan2」语法保存后会自动迁移到开关，无需手动改。
- **改IP成功但不通知**：第三方通知 Token 结尾加「||Q」。
- **自定义公网IP探测地址**：旧版写在应用ID里的「ids||url1,url2」语法保存后会自动迁移到
  「自定义公网IP探测地址」字段。
